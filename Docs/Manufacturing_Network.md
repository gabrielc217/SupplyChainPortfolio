# Manufacturing Network

## Headquarters

**Dallas, Texas**

Corporate leadership, engineering, finance, supply chain, purchasing, and digital piano final assembly.

---

## Manufacturing Plant 01

**Asheville, North Carolina**

Primary manufacturing facility for acoustic pianos.

Core operations include:

- Wood processing
- Cabinet construction
- Soundboard manufacturing
- String installation
- Final tuning
- Acoustic quality inspection

---

## Manufacturing Plant 02

**Dallas, Texas**

Primary manufacturing facility for digital products.

Core operations include:

- PCB assembly
- Electronics integration
- Keyboard action assembly
- Software installation
- Final testing
